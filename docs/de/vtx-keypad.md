# VTX Keypad

Die Tastatur dient zum Ändern und Anzeigen des VTX-Kanals oder der Sendeleistung. Aufgrund der kompakten Größe des VTX verfügen nur die folgenden VTX-Modelle über eine Tastaturbuchse:

- ECO
- Freestyle V2
- Freestyle V1 (EOL)
- RACE V2 (EOL)
- RACE V1 (EOL)
- Whoop (EOL)
