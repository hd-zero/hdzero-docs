# Antenna Replacement (Optional)

The HDZero radio has a PCB transmit antenna installed inside the top. All radios undergo transmission power testing with professional instruments at the factory to ensure each antenna delivers optimal signal transmission performance.

Nevertheless, we have reserved an interface at the top of the radio housing to allow users to extend the antenna themselves.

The antenna can be replaced with a u.FL to SMA extension cable. Knock-out the plastic hole where indicated below and install the SMA connector. Choose any 2.4Ghz SMA antenna that meets your needs.
