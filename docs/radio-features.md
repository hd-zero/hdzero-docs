# Features

- HDZero Independent OS
- Built-in OLED:
  - Sunlight-readable
  - 50FPS redering for smooth display
  - One-click toggle between Radio and ELRS menus
- Built-in ELRS TX:
  - Native ELRS OLED menu
  - MAX 250mW output power
  - Supports up to 500Hz packet rate with ultra-low latency
  - One-click quick binding
  - Bluetooth connectivitivy for wireless FPV simulator support
- Built-in ELRS Backpack:
  - Set Goggle band & channel via the radio
- Built-in Battery:
  - 4000Ah(14.8Wh) 3.7v high-capacity lithium battery
  - Over 10 hours of battery life*
- USB-C Port:
- Trainer Jack:
- Sticks can be removed and stored on the back
- Hardshell carrying case included

*Tested at 10mW/250Hz until voltage dropped to 3.2V.
