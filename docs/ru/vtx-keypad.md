# VTX Клавиатура

Клавиатура используется для изменения и отображения канала или мощности видеопередатчика. Учитывая компактные размеры видеопередатчика, разъем для подключения клавиатуры имеется только у следующих моделей:

- ECO
- Freestyle V2
- Freestyle V1 (EOL)
- RACE V2 (EOL)
- RACE V1 (EOL)
- Whoop (EOL)
