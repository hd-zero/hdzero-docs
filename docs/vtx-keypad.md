# VTX Keypad

The keypad is used for changing and display VTX channel or power. Considering the compact size of the VTX, only the following VTX models have the keypad socket:

- ECO
- Freestyle V2
- Freestyle V1 (EOL)
- RACE V2 (EOL)
- RACE V1 (EOL)
- Whoop (EOL)
